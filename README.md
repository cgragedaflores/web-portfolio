# Portfolio - Carlos Eduardo Grageda Flores

Portfolio personal desarrollado con React, TypeScript y Webpack. Presenta mis habilidades, proyectos y experiencia como Desarrollador de Aplicaciones Web.

## 🚀 Tecnologías

- React 17
- TypeScript
- Webpack 5
- CSS3 (con variables CSS y modo claro/oscuro)
- Font Awesome
- Devicons

## ✨ Características

- **Diseño Responsive**: Adaptable a todos los dispositivos
- **Modo Claro/Oscuro**: Sistema de temas con persistencia en localStorage
- **Single Page Application**: Navegación suave con scroll
- **Animaciones**: Transiciones y efectos modernos
- **Iconos Profesionales**: Uso de iconos oficiales de tecnologías

## 🛠️ Instalación

```bash
# Clonar el repositorio
git clone https://github.com/cgragedaflores/web-portfolio.git

# Entrar al directorio
cd web-portfolio

# Instalar dependencias
npm install
```

## 💻 Desarrollo

```bash
# Iniciar servidor de desarrollo
npm start
```

El sitio estará disponible en `http://localhost:8080`

## 📦 Build

```bash
# Crear build de producción
npm run build
```

## 🌐 Deploy a GitHub Pages

```bash
# Instalar dependencias (si es necesario)
npm install

# Desplegar a GitHub Pages
npm run deploy
```
